# 📖 Святой Коран - Веб-сайт на Русском языке

## ✨ Описание

Профессиональный веб-сайт на русском языке для чтения и прослушивания Святого Корана. Сайт содержит все 114 сур с русским произношением, полным арабским текстом, информацией о каждой суре и ссылками на YouTube для прослушивания рецитаций.

## 🎯 Основные возможности

✅ **114 сур Корана** - Полный текст каждой суры  
✅ **Русское произношение** - Названия сур на русском языке с транслитерацией  
✅ **Русский перевод** - Указания на наличие перевода  
✅ **YouTube ссылки** - Прямые ссылки на рецитации на YouTube  
✅ **Выбор чтецов** - 4 известных чтеца Корана  
✅ **Поиск по названиям** - Быстрый поиск сур  
✅ **Выпадающее меню** - Удобный выбор сур  
✅ **Красивый интерфейс** - Современный дизайн с фиолетовым градиентом  
✅ **Адаптивный дизайн** - Работает на всех устройствах  
✅ **Информация о суре** - Номер, количество аятов, место откровения

## 🎯 Как использовать

### 1. Локальное использование
```
1. Откройте файл index.html в веб-браузере
2. Браузер автоматически загрузит все данные Корана
3. Выберите суру из списка
```

### 2. Выбор суры
Выберите суру одним из способов:
- Нажмите на карточку в сетке сур
- Используйте выпадающее меню "Выберите суру"
- Введите название в поле поиска

### 3. Чтение суры
- Вкладка "Чтение" отображается по умолчанию
- Прокрутите вниз, чтобы прочитать все аяты
- Каждый аят содержит:
  - Текст на арабском языке
  - Перевод на русский язык
  - Номер аята

### 4. Прослушивание
- Перейдите на вкладку "Прослушивание"
- Выберите чтеца из списка
- Используйте встроенный плеер для воспроизведения
- Нажмите на красную кнопку "🎥 Слушать на YouTube" для альтернативного источника

### 5. Получение информации
- Перейдите на вкладку "Информация"
- Просмотрите подробные сведения о суре
- Узнайте значение названия и место откровения
